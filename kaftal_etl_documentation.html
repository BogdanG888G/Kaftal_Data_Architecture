Bronze Layer — Raw Data Lake

Первый слой: сырые данные как есть. Каждая из 11 сетей обрабатывается своим DAG-ом в Airflow.

BRONZE CSV → S3 (raw bucket) — 11 DAGs
👁️ FileSensor ожидает появления файлов в /opt/airflow/data/{chain}*
📤 load_to_s3_raw: загружает CSV в S3 (MinIO) bucket raw, перемещает в архив
🚫 Схема и типы данных не трогаются — всё хранится «как пришло»

Silver Layer — Нормализация

SparkSubmitOperator в каждом DAG-е запускает Spark-скрипт, читает из S3, нормализует данные и записывает в Iceberg.

SILVER Spark → Iceberg (11 таблиц)
🗺️ Маппинг колонок: каждая сеть имеет свой COLUMN_RENAME_MAP
🔢 Кастинг типов: строки → числа, даты, через SILVER_TYPES
📅 Извлечение периода: месяц/год парсятся из имени файла и данных
🔍 Дедупликация: проверка file_name перед записью
📋 Партиции: retail_chain / year / month

Gold Layer — Единая витрина (OBT)

11 Silver-таблиц склеиваются в единую плоскую таблицу (~14 млн строк) и обогащаются справочником товаров. Записывается в ClickHouse, доступна через Superset.

GOLD Spark → ClickHouse (sales_mart) — 2 DAG-а
🔗 UNION ALL: 11 Silver-таблиц → витрина 42 колонки, ~14 млн строк
📖 LEFT JOIN со справочником product_mapping
🚫 Фильтрация: brand_manual = 'Не чипсы' → исключаются
⚡ Параллельная запись: 4 партиции × 50K batch в ClickHouse
📨 Входные данные
  • 11 Iceberg Silver-таблиц
  • Справочник product_mapping (CH)
📤 Выходные данные
  • ClickHouse: default.sales_mart
  • 42 колонки × ~14 млн строк

Производительность

Реальные измеренные тайминги полной прогрузки одного «среднего» батча данных (~2,5 ГБ от одной сети).

⚡
~2 минуты на 2,5 ГБ
Archive → S3 (Bronze) → Silver Iceberg append
Archive ingest
~15 c
Чтение CSV из /data/
S3 upload
~25 c
→ MinIO bucket «raw»
Spark processing
~60 c
Маппинг + типизация
Iceberg append
~20 c
Запись в Silver
Итого: ~120 секунд (2 минуты) на полный цикл одной сети объёмом 2,5 ГБ. Bottleneck — Spark-преобразования (примерно 50% времени).

Airflow DAGs — 13 пайплайнов

13 DAG-ов: 11 для сетей (Bronze + Silver) и 2 для витрин (Gold). Все оснащены Telegram-уведомлениями.

11 DAG-ов — ETL по сетям

Task 1

wait_for_files (FileSensor)

Ожидает появления файлов /opt/airflow/data/{chain}*.

↓
Task 2

load_to_s3_raw

Загружает CSV в S3 bucket «raw» через S3Hook, перемещает в /archive/.

↓
Task 3

spark_processing (SparkSubmitOperator)

Запускает jobs/{chain}_spark_processing.py.

2 DAG-а — Витрины

DAG 12

update_product_mapping

Ежедневно 04:00. Spark → собирает уникальные product_name → INSERT новых в ClickHouse.

↓ (запускается после)
DAG 13

build_sales_mart

Ежедневно 05:00. Spark → UNION 11 Silver + JOIN mapping → TRUNCATE + INSERT в ClickHouse.
